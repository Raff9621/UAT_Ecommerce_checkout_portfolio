# 🛒 Portfolio QA & UAT: E-Commerce Checkout Release (v2.4)

Benvenuto in questo caso di studio di *User Acceptance Testing (UAT)* end-to-end realizzato per simulare la validazione pre-rilascio di una piattaforma e-commerce (Swag Labs).

L'obiettivo del progetto è dimostrare un approccio strutturato al testing orientato al business: dalla definizione dello scope e dei criteri di accettazione fino all'esecuzione dei test, alla segnalazione dei difetti e alla stesura del report di Sign-Off per gli stakeholder.

---

## 📂 Struttura dei Deliverable

1. 📋 *[01 - UAT Test Plan](./01-UAT-Test-Plan.md)* – Strategia di test, perimetro (In/Out of Scope), ambienti e criteri di ingresso/uscita (Entry/Exit Criteria).
2. 📝 *[02 - Business Requirements](./02-Business-Requirements.md)* – User Stories e Acceptance Criteria scritti in formato Gherkin (Dato / Quando / Allora).
3. 🧪 *[03 - Test Cases & Execution Log](./03-Test-Cases.md)* – Matrice completa di 8 scenari (Happy Path & Negative Testing) con esiti tracciati.
4. 🐞 *[04 - Defect Report](./04-Defect-Report.md)* – Segnalazione dettagliata di un bug funzionale/UI rilevato durante i test (BUG-01), con severità, priorità e passi di riproduzione.
5. ✅ *[05 - UAT Sign-Off Report](./05-UAT-Sign-Off-Report.md)* – Report esecutivo finale con metriche di copertura, valutazione dei rischi e decisione di rilascio (Conditional Go).

---

## 🛠️ Competenze e Metodologie Applicate
* *Metodologie:* User Acceptance Testing (UAT), Functional Testing, Exploratory Testing, Regression & Smoke Testing.
* *Documentazione QA:* Test Planning, Test Case Design, Requirement Traceability, Defect Management, Sign-Off Reporting.
* *Strumenti:* GitHub (Markdown Documentation & Version Control), Browser DevTools.
